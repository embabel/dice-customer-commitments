# Commitments workbench

Mode: Operate.

The opening viewport puts two signed dates beside the evidence behind them. The operator can ask a question at this point, import the later signed amendment, or replay the opening record. Sales targets, requests, spoken commitments, and tasks appear separately under the question panel, with a source on each row.

The historical state changes the question scope and disables ingestion. The source reader follows the selected record and never links to a passage the view does not contain.
